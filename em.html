電磁気ラボ

式だけだと追いにくい、場の広がりと向きを、動かして確かめるためのページです。静電場、磁場中の荷電粒子、電磁波、電磁誘導、RLC回路、アンペールの法則の6つを用意しています。

電気力線と等電位線は、いつも直角に交わる

電荷を置いたり動かしたりして、電場(力線)と電位(等電位線・色)がどう変わるかを見ます。画面を指でなぞると、その場所の E と V が読めます。

置く電荷の大きさ
はじめの配置

電荷の合計0
調べた点の |E|—
調べた点の V—

見どころ

  • 力線は正電荷から出て、負電荷に入ります。本数は電荷の大きさに比例させてあり、大きさ 1 のとき 12 本です。
  • 等電位線は、力線といつも直角に交わります。等電位線が詰まっているところは電位が急に変わるところで、電場が強いところでもあります。
  • 「同符号2つ」にすると、2つの電荷の真ん中に力線のない場所ができます。そこでは E = 0 ですが、V は 0 ではありません。調べて確かめてください。
  • 「2 と −1」では、負電荷に入りきらなかった力線が外へ抜けていきます。電荷の合計が 0 でないと、遠くから見て単独の電荷に近づくためです。

式

V(r) = Σ qi / |r − ri| E = −∇V = Σ qi (r − ri) / |r − ri|³　(係数 1/4πε0 = 1)

紙面の上に置いた3次元の点電荷を、その面で切った図です。電荷のすぐ近くは表示のため少しなめらかにしてあります。

もう少し詳しく

点電荷のまわりの電場は E = q/r² (ここでは比例定数を 1 としています)で、複数の電荷では、それぞれの電場のベクトルの和になります(重ね合わせの原理)。電気力線は、各点で電場の向きを接線とする線で、正電荷から出て負電荷に入り、途中で枝分かれも交差もしません。

電位は V = q/r で、足し算だけで求まります。電場と電位は E = −∇V で結ばれていて、電場は電位が最も急に下がる向きを向き、その向きは等電位線に直角です。等電位線が混んでいるところは、電位が急に変わるところなので、電場が強いところです。

同符号の電荷では、電荷の間に電場がゼロの点ができ、そこで力線がよけ合います。正負が近い双極子では、遠くの電場は 1/r³ で急速に弱まります。これは正負の電場が打ち消し合うからで、四重極では、さらに打ち消しが進みます。

試してみよう

  1. 「双極子」を選び、電荷を近づけたり離したりします。遠くの力線が、どう変わるでしょうか。
  2. 「同符号2つ」で、2つの電荷の真ん中あたりの電位を見ます。電場がゼロでも、電位はゼロではありません。
  3. 「2 と −1」を選びます。力線は、大きいほうから出て、半分が無限遠へ向かいます。

よくある疑問

力線の本数に意味はありますか。
ここでは、電荷の大きさに比例した本数を引いています。力線の混み具合は、3次元では電場の強さに対応しますが、紙面の上では目安です。
電位が高いところに、正電荷を置くとどうなりますか。
電位の低いほうへ、力線に沿って動きます。ちょうど、斜面の上のボールのように考えられます。

電場と磁場の中で、粒子はなぜ横に流れていくのか

磁場は粒子を円運動させます。そこに電場や磁場の勾配が加わると、円の中心が少しずつ横へずれていきます。これがドリフトです。

はじめの設定
電荷の符号
周期 2π/B0
旋回半径0
ドリフト速度(理論)0
ドリフト速度(測定)計測中
運動エネルギー0

見どころ

  • 電場がないとき、粒子は一定の速さで円を描きます。旋回半径は速さに比例しますが、周期は速さによりません。速さのスライダーを動かして確かめてください。
  • 「E×B」を選ぶと、粒子は電場の向きではなく、E と B の両方に直角な向きへ流れます。電荷の符号を切り替えても、流れる向きは変わりません。正負で逆向きに流れる、と考えがちなところです。
  • 「∇B」を選ぶと、磁場の強い側で円が小さく、弱い側で大きくなるため、円が閉じずにずれていきます。こちらは正負で逆向きに流れます。
  • 紫の十字は旋回の中心です。ドリフトとは、この点の動きのことです。

式

m dv/dt = q (E + v × B) r = m v⊥ / (|q| B),　T = 2πm / (|q| B) vE = E × B / B²,　v∇B = (m v⊥² / 2qB) (B × ∇B) / B²

電荷と質量の比を ±1 とした単位で計算しています(m = 1、q = ±1)。磁場は紙面から手前向きです。

もう少し詳しく

磁場だけがあると、荷電粒子は磁場に垂直な面内で円運動をします。回転の角振動数はサイクロトロン角振動数 ωc = qB/m、半径は r = mv/(qB) で、粒子の速さが違っても、1周にかかる時間は同じです。

力 F が加わると、円運動の中心(ガイディングセンター)が、F×B の向きに、速さ F/(qB) で流れていきます。これがドリフトです。電場なら、ドリフトの速さは E/B となり、電荷の符号にも、質量にもよりません。そのため、E×B ドリフトでは、＋と−が同じ向きに流れます。

磁場に勾配があると、磁場が強いところでは回転半径が小さく、弱いところでは大きくなります。そのため、1周するたびに少しずつずれて、全体として横へ流れます(∇B ドリフト)。この場合は、＋と−が逆向きに流れます。これらは、核融合のプラズマの閉じ込めや、オーロラが生じる地球の磁気圏の理解に欠かせません。

試してみよう

  1. 「E×B」を選び、＋と−を切り替えます。どちらも同じ向きに流れます。
  2. 「∇B」を選び、＋と−を切り替えます。今度は逆向きに流れます。
  3. 磁場 B を強くします。円は小さくなり、E×B ドリフトの速さは E/B に従って遅くなります。

よくある疑問

粒子はなぜ、電場の向きには進まないのですか。
電場で加速しても、速くなると円の半径が大きくなって、磁場に曲げられるからです。1周のあいだに、加速と減速が打ち消し合うため、電場の向きには進まず、垂直に流れます。
磁場は粒子に仕事をしますか。
しません。磁場の力は速度に垂直なので、速さは変わりません。

電場と磁場が、互いを生みながら進んでいく

マクスウェル方程式を1次元でそのまま解いています。波を媒質に入れると、速さと波長が変わり、境界で一部が跳ね返されます。

再生速度
媒質中の速さ—

反射率(理論)—

見どころ

  • E(青)と B(橙)はいつも同じ位相で、進む向きとは直角です。E の向きから B の向きへ右ねじを回したとき、ねじの進む向きが波の進む向き(E × B)です。
  • 媒質に入ると、周波数はそのままで、速さが c/n、波長が λ/n になります。波が詰まって見えるのはそのためです。
  • 厚い媒質の境界では、反射率 ((n−1)/(n+1))² の分だけ跳ね返されます。n = 2 なら約 11%、n = 3 なら 25% です。
  • 「薄い膜」で厚さを 0.5 や 1.0 にすると反射がなくなり、0.25 や 0.75 にすると反射が最大になります。表と裏で反射した波が、重なって強め合ったり打ち消し合ったりするためです(薄膜干渉)。
  • 媒質の中では、B の振幅が E の n 倍になっています。波形の高さの違いに注目してください。

式

∂Bz/∂t = −∂Ey/∂x ε ∂Ey/∂t = −∂Hz/∂x　(c = 1/√(εμ),　n = √ε)

1次元の差分法(FDTD)で、E と H をずらした格子の上で交互に更新しています。波束のときの反射率は、波長の幅が狭い場合の近似です。

もう少し詳しく

変化する磁場は電場を生み(ファラデーの法則)、変化する電場は磁場を生みます(マクスウェルの補正項)。この2つが互いを生みながら、真空中を速さ c = 1/√(ε0μ0) で進むのが電磁波です。電場と磁場は、進む向きに垂直で、同じ位相で振動します。

屈折率 n の媒質では、波の速さは c/n になり、波長は 1/n に縮みます(振動数は変わりません)。境界では、波の一部が反射し、反射率は ((n−1)/(n+1))² です。n = 1.5 のガラスなら約 4% で、屈折率が高い側で反射すると、位相が π だけ反転します。

薄い膜では、上の面で反射した波と、下の面で反射した波が重なって、干渉します。膜の厚さが、媒質中の波長のちょうど半分の整数倍のときは、2つの反射が打ち消し合い、反射率がゼロになります(反射防止膜は、屈折率と厚さを選んで、この打ち消しを利用しています)。1/4 波長の奇数倍のときは、反射が最大になります。シャボン玉や油膜が色づくのは、波長ごとに干渉の条件が違うからです。

試してみよう

  1. 「連続波」で、「厚い媒質」を選びます。媒質に入ると、波長が短くなる様子が見えます。
  2. 「薄い膜」で、厚さを 0.5 倍にします。反射がほぼゼロになります。0.25 倍では、反射が最大になります。
  3. 屈折率 n を大きくして、境界での反射が増えるのを確かめます。

よくある疑問

電場と磁場のどちらが先に生まれるのですか。
どちらが先ということはなく、互いを生みながら進んでいきます。波源がまず電流や電荷の運動として現れ、その周りに電磁波が広がります。
反射した波が、反対向きに進むのはなぜですか。
境界の両側で、電場と磁場がなめらかにつながる条件を満たすには、反射する波が必要だからです。

磁石を動かした瞬間にだけ、コイルに電圧が生まれる

コイルを貫く磁束が変化すると、その変化を打ち消す向きの起電力が生じます。磁石がコイルの中で止まっていれば、強い磁場の中でも電圧はゼロです。

磁石の動かし方(図を触っても動かせます)
磁石の向き
磁束 Φ0
起電力 ε0
誘導電流—
直近の |ε| の最大0

見どころ

  • 「通過」では、起電力は+と−の山を1つずつ作ります。磁石が近づくときと遠ざかるときで、磁束の変化の向きが逆だからです。
  • 山の位置は、コイルの半径の半分だけ手前と奥です。磁石がちょうどコイルの真ん中にあるときは、磁束は最大でも、その変化がないので起電力はゼロです。
  • 速さを2倍にすると、山の高さは2倍、幅は半分になります。山の面積(= 磁束の変化の総量)は変わりません。
  • 「手で動かす」で磁石をコイルの中に置いたまま止めると、起電力は消えます。「磁場がある」ことと「磁場が変化している」ことは別です。
  • 緑の矢印は、誘導電流が磁石に及ぼす力です。近づくときは押し返し、離れるときは引き止めます。これがレンツの法則です(向きは正確、長さは目安)。

式

ε = −N dΦ/dt Φ(z) ∝ R² / (R² + z²)3/2

磁石を点の磁気双極子として扱い、軸上の磁束 Φ(z) を使っています。コイルの自己インダクタンスは無視しているので、誘導電流がつくる磁場は計算に入れていません。

もう少し詳しく

コイルを貫く磁束 Φ が時間変化すると、コイルに起電力 ε = −N dΦ/dt が生じます(ファラデーの法則)。マイナス符号は、誘導電流がつくる磁場が、もとの磁束の変化を打ち消す向きになることを表します(レンツの法則)。

大事なのは、磁束そのものではなく、その変化の速さです。磁石がコイルの中で静止していれば、磁束は最大でも起電力はゼロです。逆に、同じ磁石でも速く動かすほど、短い時間で大きな起電力が生じます。

レンツの法則は、エネルギー保存の表れです。誘導電流が磁石の動きを妨げる力を及ぼすので、磁石を動かすには仕事が必要で、その仕事が電気エネルギー(熱)に変わります。もし逆向きに加速されるなら、エネルギーが無から生まれてしまいます。

試してみよう

  1. 「通過」で速さを 1 と 2 にして、起電力の山の高さと幅を比べます。
  2. 「手で動かす」で磁石をコイルの真ん中へ持っていき、止めます。そのあと左右にゆっくり、次に素早く動かして、起電力の大きさを比べます。
  3. 磁石の向きを反転して、起電力の山が上下逆になることを確かめます。

よくある疑問

起電力が +と−の2つの山になるのはなぜですか。
近づくときは磁束が増え、離れるときは減るからです。磁束の変化の向きが逆なので、誘導電流の向きも逆になります。
巻き数を増やすと何が変わりますか。
巻き数 N の分だけ磁束が直列に足し合わされるので、起電力が N 倍になります。この図では、同じ磁束が N 回貫くものとして扱っています。

交流の周波数を変えると、回路はある周波数だけで大きく応える

コイルとコンデンサと抵抗をつないだ回路に、交流電圧をかけます。コイルとコンデンサの効果が打ち消し合う周波数で、電流は最大になります。

共鳴 ω₀ = 1/√(LC)0
Q 値 ω₀L/R0
インピーダンス |Z|0
位相(電流の遅れ)0
電流の振幅(理論)0
電流の振幅(測定)計測中
平均の消費電力0

見どころ

  • 「ω を ω₀ に合わせる」を押すと、電流が電圧と同じ位相になり、振幅が V₀/R の最大値まで育ちます。このとき |Z| = R です。
  • ω が ω₀ より小さいとコンデンサの効果が勝って電流は電圧より進み、大きいとコイルの効果が勝って遅れます。共鳴曲線の橙の線がそれです。
  • 抵抗 R を小さくすると、共鳴のピークが鋭くなります。山の半値幅は R/L で、Q 値が大きいほど狭くなります。ラジオの選局はこの性質を使っています。
  • 「静止から始める」と、電流が最終的な振幅に落ち着くまでの過渡的な振る舞いが見えます。R が小さいほど落ち着くまで時間がかかります。
  • 電力を消費するのは抵抗だけです。コイルとコンデンサはエネルギーをため込んで返すだけなので、位相がずれているほど平均の消費電力は小さくなります。

式

L d²q/dt² + R dq/dt + q/C = V0 cos ωt |Z| = √(R² + (ωL − 1/ωC)²),　tan φ = (ωL − 1/ωC) / R

電圧の振幅 V₀ = 1 の無次元の単位で、4次のルンゲ・クッタ法で微分方程式を解いています。曲線は定常状態の理論値です。

もう少し詳しく

抵抗 R、コイル L、コンデンサ C を直列につないで、交流電圧 V₀cos ωt をかけると、電流は電圧とは別の位相で振動します。コイルは電流の変化に逆らい、コンデンサは電荷がたまると電圧を押し返すので、どちらも電流の流れを妨げます。

コイルの効果 ωL と、コンデンサの効果 1/ωC は、符号が逆に働きます。ω² = 1/LC のときに両者がちょうど打ち消し合い、残る抵抗は R だけになって、電流が最大になります。これが共鳴です。強制振動のばねとおもりと、まったく同じ方程式です。

共鳴の鋭さは Q 値 = ω₀L/R で決まります。Q が大きい回路は、狭い範囲の周波数にだけ強く応えるので、ラジオやフィルターの選局に向いています。一方で、状態が落ち着くまでの時間も長くなります。

試してみよう

  1. 「ω を ω₀ に合わせる」を押して、電流の振幅が最大になり、電圧と同じ位相になるのを確かめます。
  2. 抵抗 R を 0.1 まで下げ、ω を ω₀ のまわりで少しずつ動かして、ピークの鋭さを見ます。
  3. 「静止から始める」を押して、振幅が育つまでの過渡的な振る舞いを観察します。

よくある疑問

電源の周波数と同じ周波数で振動するのはなぜですか。
十分に時間がたつと、回路が自分で持っていた固有の振動は抵抗で減衰して、電源に引っ張られた振動だけが残るからです。静止から始めた直後は、2つが混ざって見えます。
共鳴しても、電圧より電流が大きくなることはありますか。
電流と電圧は単位が違うので直接は比べられませんが、コイルとコンデンサにかかる電圧は、Q が大きければ電源電圧の Q 倍にもなります。

磁場をぐるっと一周たどると、囲んだ電流の合計がわかる

紙面に垂直な電流がつくる磁場の中に、円を描きます。円に沿った磁場の合計は、磁場がどんな形でも、円の中を通る電流の合計だけで決まります。

電流の配置
∮B·dl(数値積分)0
囲んだ電流の合計 ΣI0
円の中の導線0

見どころ

  • 導線が1本のとき、円の中心を導線からずらしても、半径をどう変えても、導線を囲んでいる限り ∮B·dl は同じ値です。円周が長くなるぶん、磁場が弱くなって帳尻が合います。
  • 円の半径を広げて導線の位置をまたぐと、値が階段状に変わります。下のグラフの段差がその瞬間です。
  • 導線を円の外へ出すと、円の上の磁場はゼロではないのに、一周の合計はゼロになります。行きに押された分を、帰りに引き戻されるからです。
  • 「逆向き2本」の円で両方を囲むと、磁場は円上のあちこちで強く向きもばらばらなのに、合計はちょうど0です。囲んだ電流の合計が0だからです。

式

∮ B · dl = μ0 I内 直線電流: B = μ0 I / (2πr)

μ₀ = 1 の単位です。磁場は電流のまわりを右ねじの向きに回ります。磁力線は、磁場の向きに沿って1本ずつ数値的にたどっています。導線のすぐそばを通る円では、積分が定まらないので「—」を表示します。

もう少し詳しく

アンペールの法則は、磁場 B を閉じた経路に沿って一周足し合わせた値(周回積分)が、その経路が囲む面を貫く電流の合計に μ₀ をかけたものに等しい、という法則です。経路の形や、磁場がどのように分布しているかには、よりません。

直線電流のまわりの磁場は、電流から離れるほど B = μ₀I/2πr で弱くなります。円周は 2πr で長くなるので、掛け合わせると r が消えて、半径によらず一定になります。導線を囲まない経路では、磁場の「行き」と「帰り」が打ち消し合って、周回積分はゼロになります。

電流が対称な形をしているときは、磁場の向きと大きさが経路上で一定になるので、この法則だけから磁場の大きさが求まります。無限に長いソレノイドの内部の磁場がその例です。ただし、磁場が時間変化するときは、マクスウェルの変位電流の項が必要になります。

試してみよう

  1. 「1本」で、円の中心を導線からずらしても、数値が 1 のままであることを確かめます。
  2. 「逆向き2本」で、円の半径を広げて、導線をまたぐたびに値が変わる様子を見ます。
  3. 導線を円の外へドラッグして、円の上の磁場は残るのに、合計がゼロになることを確かめます。

よくある疑問

磁場は導線を囲んでいない部分にも、あるのですか。
あります。囲んでいなくても、磁場は導線のまわりのどこにでも存在します。周回積分がゼロになるのは、磁場がないからではなく、一周すると打ち消し合うからです。
円の外にある電流は、円上の磁場に影響しないのですか。
影響します。円上の磁場は、すべての電流の寄与の合計です。ただし、周回積分の値には、円が囲んだ電流だけが現れます。
