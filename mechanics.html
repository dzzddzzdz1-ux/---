力学ラボ

式では追いにくいところを、動かして確かめるためのページです。二重振り子、位相空間、回転座標系、連成振動、強制振動、ケプラー問題の6つを用意しています。

ほぼ同じ出発点が、なぜ別の動きになるのか

二重振り子を2つ、初期角度をわずかにずらして同時に動かします。最初は重なって見えますが、しばらくすると別々の動きになります。

再生速度
経過時間0.0 s
AとBの差 |Δ|0
広がる速さ λ(目安)計測中
Aのエネルギーのずれ0

見どころ

  • 差のグラフが右上がりの直線になっている間は、差が指数関数的に増えています。直線の傾きが、カオスの強さを表すリアプノフ指数 λ です。
  • 差が 1 rad 前後で頭打ちになると、AとBは無関係な動きをします。δ を 10-3 から 10-6 に変えても、頭打ちまでの時間は ln(1000)/λ ほどしか延びません。
  • エネルギーのずれは、数値計算の精度の目安です。刻み 2 ms の4次ルンゲ・クッタ法で、m = 1 kg、ℓ = 1 m として計算しています。
L = ½(m1+m2)ℓ12ω12 + ½m2ℓ22ω22 + m2ℓ1ℓ2ω1ω2cos(θ1−θ2) + (m1+m2)gℓ1cosθ1 + m2gℓ2cosθ2　(ωi = dθi/dt) d/dt(∂L/∂ωi) = ∂L/∂θi

もう少し詳しく

二重振り子は、エネルギーが保存し、運動方程式も決まっている「決定論的」な系です。それでも長く見ると予測できなくなるのは、わずかな初期の違いが指数関数的に拡大するからです。この拡大の速さを表すのがリアプノフ指数 λ で、差は目安として eλt に比例して増えます。

差が増えるのは、差が系全体の大きさ程度になるまでです。その先は、AもBも同じ範囲の中を動くので、差は頭打ちになります。画面右のグラフで右上がりの直線に見える部分が、拡大の最中にあたります。

初期の差を 10 分の 1 にしても、予測できる時間は ln 10 / λ だけしか延びません。観測精度を何桁よくしても、予測できる期間は少ししか長くならないのが、カオスの本質的な難しさです。天気予報に限界があるのも、同じ理由です。

試してみよう

  1. δ を最小にして、AとBが別々になるまでの時間を測ります。δ を 10 分の 1 にすると、時間はどれだけ延びるでしょうか。
  2. θ1、θ2 をどちらも小さい角度(10° くらい)にします。拡大が起きず、2つがきれいに重なったまま動くはずです。エネルギーが小さいと、運動は規則的になります。
  3. θ1、θ2 を大きくして(120° 以上など)、先端の軌跡を表示します。軌跡が複雑に絡み合う様子が見られます。

よくある疑問

乱数を使っているのですか。
いいえ。計算に乱数は使っていません。同じ初期条件なら、毎回まったく同じ動きになります。予測しにくいのは、ランダムだからではなく、初期条件への敏感さのためです。
長い時間たったあとの軌道は正しいのですか。
数値計算の丸め誤差も同じように拡大されるので、拡大が進んだあとの軌道は「本物の運動」とは一致しません。ただ、広がる速さやエネルギーの保存といった統計的な性質は信頼できます。

平面上の1点が、振り子の状態そのもの

横軸が角度 θ、縦軸が角速度 ω です。右の平面をタップまたはドラッグすると、その点から振り子が動き出します。

初期条件の例
エネルギー E(最新の軌道)0
運動の種類—
周期 T / T0—

見どころ

  • 小さく振ると、軌道はほぼ楕円になります。単振動の位相空間と同じ形です。
  • 振幅を大きくすると、軌道は楕円からゆがみ、周期 T が単振動の周期 T0 より長くなります。T / T0 の表示で確かめられます。
  • 破線(分離線)は、真上でちょうど止まる運動の軌道です。その外側では、振り子は往復せずに回り続けます。
  • 減衰を入れると、軌道は原点に巻き込まれていきます。回転していた振り子も、やがて往復運動に変わります。
d2θ/dt2 = −sinθ − γ dθ/dt　(時間の単位は 1/ω0 = √(ℓ/g)) E = ½(dθ/dt)2 − cosθ T/T0 = 2K(k)/π,　k = sin(θmax/2)　(K は第1種完全楕円積分)

もう少し詳しく

振り子の状態は、角度 θ と角速度 ω の2つの数で決まります。この2つを座標にした平面が位相空間で、1つの点が系の状態を、1本の曲線が運動全体を表します。運動方程式が一意に解けるので、異なる軌道が交わることはありません。

小さく振る間は、軌道は閉じた曲線(ほぼ楕円)になります。エネルギーが増えると曲線は広がり、振り子が真上に立つ点(θ = π)を通る特別な軌道、セパラトリクスに近づきます。その外側では、振り子は往復をやめて回り続けます。往復と回転の境目が、一本の線ではっきり見えるのが位相空間の良いところです。

セパラトリクスに近づくほど、真上付近で長い時間を過ごすので、周期は長くなります。周期は T/T0 = 2K(k)/π で、振幅が大きくなるほど T0 より長くなり、境目では無限大になります。減衰を加えると、軌道は渦を巻いて θ = 0 の点へ吸い込まれます。

試してみよう

  1. 「小さく振る」と「大きく振る」で、T/T0 の値を比べます。小さい振れでは 1 に近く、大きくなると増えます。
  2. 減衰 γ を 0 にして、軌道が閉じたままになることを確認します。次に γ を少し増やして、渦巻きながら中心へ向かう様子を見ます。
  3. 「真上の近くから」を押します。ほんの少しの違いで、往復になるか回転になるかが変わります。

よくある疑問

θ = π と θ = −π は同じ点ですか。
同じ状態です。角度は 2π ごとに繰り返されるので、位相空間は横方向につながった帯(円柱)になっています。画面の左右の端は、つながっていると考えてください。
なぜ軌道は交わらないのですか。
状態が決まれば、その先の運動が一通りに決まるからです。もし交われば、同じ状態から2通りの未来が生まれてしまいます。

回る台の上では、まっすぐ進むボールが曲がる

台の中心から、縁の紫の目印をめがけてボールを転がします。台の外から見ると直進ですが、台の上から見ると曲がります。

再生速度
経過時間0.00 s
台の回転角 Ωt0°
縁での目印とのずれ0°

見どころ

  • 左の静止系では、ボールに力は働かず直進します。曲がって見えるのは、台のほうが回っているからです。
  • 右の回転系でボールが曲がることを「力が働いた」と解釈すると、速度に垂直なコリオリ力と、中心から外向きの遠心力が必要になります。矢印の長さは、速度は速度どうし、力は力どうしで比べられます。
  • 縁に着いたときの目印とのずれ角は ΩR/v です。速く転がすほどずれは小さくなり、Ω の符号を変えると曲がる向きが逆になります。
ma′ = F − 2mΩ×v′ − mΩ×(Ω×r′)　(′ は回転系での量) r′(t) = R(−Ωt) r(t)　(R は回転行列。ここでは F = 0)

もう少し詳しく

台の外(静止系=慣性系)では、ボールに力は働かず、直進します。台の上(回転系)から見て曲がるのは、見ている台のほうが回っているためです。回転系でニュートンの運動方程式を使おうとすると、実際には存在しない「見かけの力」を足さないと、観測と合いません。

見かけの力は2つあります。コリオリ力 −2mΩ×v′ は、速度に垂直で、動いているものにだけ働きます。遠心力 −mΩ×(Ω×r′) は、位置に依存し、止まっているものにも働きます。コリオリ力は速度に垂直なので、仕事をしません。

地球は自転しているので、地上の風や海流にもコリオリ力が働きます。低気圧のまわりの風が北半球で反時計回りに巻くのは、気圧の低い中心へ向かう空気が、進行方向の右へそれるためです。ただし、お風呂の排水口の渦の向きは、コリオリ力ではなく容器の形や水の初期の動きで決まります。

試してみよう

  1. Ω の符号を反転して、曲がる向きが逆になることを確認します。
  2. ボールの速さ v を 2 倍にします。縁でのずれ角 ΩR/v が半分になるのを、画面の数値で確かめます。
  3. Ω をゼロにします。回転系でも直進になり、見かけの力が消えます。

よくある疑問

遠心力は本当にあるのですか。
慣性系にはありません。回転する座標系で運動を記述するときだけ現れる、見かけの力です。ただし回転系に乗っている人は、実際にそれを感じます。
コリオリ力はなぜ速度に垂直なのですか。
定義が外積 Ω×v′ だからです。外積は、2つのベクトルのどちらにも垂直になります。

複雑な振動も、2つの「基準モード」の重ね合わせ

ばねでつながった2つのおもりを動かします。片方だけ引いて離すと、エネルギーが行ったり来たりします。この動きは、2つの単純な振動(基準モード)の足し合わせです。

はじめの引き方
再生速度
同位相モード ω+
逆位相モード ω−
エネルギーが移りきる時間
経過時間

見どころ

  • 「同じ向き」では2つのおもりが常に同じ動きをし、ばねの強さに関係なく角振動数は 1 のままです。結合ばねは伸び縮みしないからです。
  • 「逆向き」では中央がずっと動かず、結合ばねが毎回縮むぶん振動が速くなります(ω− = √(1+2kc))。
  • 「片方だけ」は2つのモードを半分ずつ混ぜた状態です。2つの角振動数がわずかに違うので「うなり」が生じ、エネルギーが完全に反対側のおもりへ移ります。結合を弱くするほど、移るのに時間がかかります。
x1 = (a1+a2)/2 · cos ω+t + (a1−a2)/2 · cos ω−t x2 = (a1+a2)/2 · cos ω+t − (a1−a2)/2 · cos ω−t ω+ = √(k/m),　ω− = √((k+2kc)/m)　(ここでは m = k = 1)

もう少し詳しく

2つのおもりを別々に見ると複雑な動きですが、「同じ向きに動く」「逆向きに動く」という2つの組み合わせで見ると、それぞれが単純な単振動になります。これが基準モードです。どんな初期条件の動きも、基準モードの重ね合わせで表せます。

同位相のモードでは結合ばねが伸び縮みしないので、角振動数は結合の強さによらず √(k/m) です。逆位相のモードでは、結合ばねも毎回縮み、復元力が増えるぶん角振動数が √((k+2kc)/m) と大きくなります。

片方だけ引くと、2つのモードが半分ずつ混ざります。わずかに違う2つの振動の和なので「うなり」が生じ、エネルギーが少しずつ反対側へ移ります。移りきる時間は π/(ω−−ω+) で、結合が弱いと kc にほぼ反比例して長くなります。N 個のおもりをつなぐと、基準モードは N 個になり、N を大きくすると波の伝わりに近づきます。

試してみよう

  1. kc を最小にして、「片方だけ」を試します。エネルギーが移りきるまでの時間が長くなります。
  2. 「同じ向き」「逆向き」を選び、kc を動かします。「同じ向き」では周期が変わらず、「逆向き」だけが変わります。
  3. 「片方だけ」で、おもり1の動きが止まって見える瞬間を探します。表示された「移りきる時間」と一致するはずです。

よくある疑問

エネルギーは失われているのですか。
いいえ。ばねの間でやり取りされるだけで、全体のエネルギーは一定です。うなりの間、2つのおもりのエネルギーが行き来します。
現実の例はありますか。
二酸化炭素などの分子の振動(対称伸縮と逆対称伸縮)や、同じ梁に吊るした2本の振り子が代表的です。分子の振動は、赤外線の吸収として観測されます。

ゆらす速さを合わせると、振れが大きく育つ

ばねのおもりを、外から周期的な力でゆすります。ゆする角振動数 ω が固有角振動数(ここでは 1)に近いと、振れ幅が一気に大きくなります。これが共鳴です。

振幅(理論)
振幅(直近1周期の実測)
位相の遅れ
振幅が最大になる ω
Q 値(1/γ)

見どころ

  • はじめは固有振動と駆動による振動が混ざって、うねるような動きになります(過渡応答)。減衰で固有振動が消えると、駆動と同じ角振動数の一定の振動(定常応答)だけが残ります。
  • ω が小さいうちはおもりが力に同調し、ω が大きいと逆向きに遅れて動きます。位相の遅れは ω の小さい側で 0、共鳴付近で約 90°、大きい側で 180° に近づきます。
  • γ を小さくするほどピークは高く鋭くなります。ピークの位置は固有角振動数 1 ではなく √(1 − γ²/2) で、わずかに低い側へずれます。
x″ + γx′ + x = F cos ωt A(ω) = F / √((1 − ω²)² + (γω)²),　tan δ = γω / (1 − ω²)

もう少し詳しく

外力 F cos ωt を加えると、はじめは固有の振動と混ざった複雑な動きが出ますが、減衰のために固有の振動は e−γt/2 で消え、駆動と同じ角振動数の一定の振動だけが残ります。この定常状態の振幅と位相は、初期条件によらず決まります。

振幅は A = F/√((1−ω²)² + (γω)²) です。ω が固有角振動数 1 に近いと分母が小さくなり、振幅が大きくなります。位相は、ω が小さいうちは外力と同調し、共鳴付近で約 90°、ω が大きいと約 180° 遅れます。この遅れの変化が急になるのが、共鳴の特徴です。

γ が小さいほどピークは高く鋭くなり、Q = 1/γ はその鋭さの目安です。振幅が最大になる角振動数は √(1−γ²/2) で、固有角振動数よりわずかに低くなります(吸収するエネルギーが最大になるのは、ちょうど ω = 1 のときです)。ラジオの同調回路は、この鋭さを利用して、聞きたい局の周波数だけを取り出しています。

試してみよう

  1. γ を 0.05 にして、ω を 0.5 から 1 へ少しずつ近づけます。振幅が急に大きくなります。
  2. 「共鳴に合わせる」を押して、振幅が育つ様子を見ます。γ が小さいほど、定常になるまで時間がかかります(目安は 2/γ)。
  3. ω を 1.5 以上にします。おもりは外力と逆向きに、小さく動きます。

よくある疑問

共鳴すると、振幅は無限大になりますか。
摩擦(γ)がある限り、有限です。摩擦がまったくないときだけ、振幅は時間とともに限りなく大きくなります。
グラフの「実測」と「理論」が違うのはなぜですか。
実測値は、直近の1周期の最大値です。動かし始めや、ω・γ を変えた直後は、固有の振動が残っているので、理論値(定常状態)とずれます。時間がたつと一致します。

初速を変えるだけで、円・楕円・放物線・双曲線

太陽のまわりを動く天体を、初速だけ変えて試します。軌道が楕円になるか飛び去るかは、エネルギーの符号で決まります。

よく使う値
軌道の種類
離心率 e
長半径 a
周期 T
全エネルギー E
角運動量 L

見どころ

  • 速さが v0 = 1 のときは円です。それより速いと出発点が近日点(最も近い点)になり、遅いと遠日点(最も遠い点)になります。
  • 扇形の面積はどれも等しく、近いところでは細長く、遠いところでは短く太くなります。角運動量が保存するので、近くでは速く、遠くでは遅く動きます(ケプラーの第2法則)。
  • v0 = √2 ≈ 1.414 でちょうど E = 0 の放物線になり、それを超えると二度と戻らない双曲線になります。
  • 周期 T = 2πa3/2 は長半径だけで決まります(第3法則)。
E = v²/2 − GM/r,　a = −GM/(2E),　T = 2π√(a³/GM) r = a(1−e²) / (1 + e cos θ),　r近日 = a(1−e) ここでは GM = 1、太陽は原点に固定

もう少し詳しく

太陽(質量 M)の重力の下での運動は、力が 1/r² に比例する場合の運動です。この力は中心力なので、角運動量 L が保存し、動径方向と角度方向に分けて考えられます。L が一定ということは、単位時間に掃く面積が一定ということです(第2法則)。

エネルギー E = v²/2 − GM/r の符号が、軌道の種類を決めます。E < 0 なら楕円(円を含む)、E = 0 なら放物線、E > 0 なら双曲線です。楕円の長半径は a = −GM/(2E) で、周期は T = 2π√(a³/GM) (第3法則)。半径 1 の円軌道の速さは √(GM/r) = 1 で、脱出に必要な速さはその √2 倍です。

1/r² の力は、軌道が閉じる特別な力です。離心率ベクトルが保存するために、楕円が少しもずれずに同じ形を繰り返します。実際の惑星では、他の惑星の引力や相対論の効果で、近日点がゆっくり動きます。水星の近日点の移動のうち、一般相対性理論で説明される分は、100 年で約 43 秒角です。

試してみよう

  1. v0 を 1.0、1.1、1.2、1.3 と変えます。離心率と周期が、どう変わるでしょうか。
  2. v0 = 0.8 にして、出発点が遠日点になることを確かめます。そのあと、近日点では速く、遠日点では遅く動くことを、右のグラフで確認します。
  3. 「放物線」と「双曲線」を押して、天体が戻らずに飛び去るのを見ます。

よくある疑問

なぜ円軌道の速さは 1 なのですか。
円運動に必要な向心力 v²/r が、重力 GM/r² に等しいからです。GM = 1、r = 1 なので、v = 1 です。
なぜ放物線の初速は √2 なのですか。
E = v²/2 − 1/r = 0 となる速さが、r = 1 では v = √2 だからです。これが、その位置からの脱出速度です。
