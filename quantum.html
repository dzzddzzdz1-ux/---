量子力学ラボ

波動関数は、式では追えても絵が浮かびにくいものです。閉じ込められた粒子、トンネル効果、不確定性関係、調和振動子、水素原子の軌道、スピンの6つを、動かして確かめます。

閉じ込められた波は、なぜ「とびとびのエネルギー」になるのか

幅 1 の井戸に閉じ込めた粒子の波動関数を、固有状態(定在波)の足し合わせとして動かします。混ぜる割合を変えて、確率の動きを見てください。

はじめの状態
再生速度
時刻 t / 復活の周期0
位置の平均 ⟨x⟩0
エネルギーの平均 ⟨E⟩0
確率の振動の周期—

見どころ

  • 「n = 1」「n = 2」のように固有状態を1つだけ選ぶと、確率の分布は止まって見えます。実部と虚部は回っていますが、2乗すると動きが消えます。これが定常状態です。
  • n 番目の状態は、節(確率がゼロの点)が n − 1 個あります。波長が短いほどエネルギーが高く、En は n² に比例します。
  • 複数を混ぜると、成分ごとに位相の進む速さが違うので、確率の山が壁の間を行き来します。「1 + 2」では、周期 2π/(E2 − E1) で振動します。
  • En が n² に比例するため、t = 4/π(右上のメーターで 1.00)のとき、すべての成分の位相がそろい、最初の形に完全に戻ります。

式

φn(x) = √(2/L) sin(nπx/L),　En = n²π²ħ² / (2mL²) ψ(x, t) = Σ cn φn(x) e−iEnt/ħ

ħ = m = L = 1 の単位で計算しています。混ぜる量は、合計が 1 になるよう自動で調整されます。

もう少し詳しく

箱の中の波(波動関数)は、両端で必ず 0 にならなければなりません。そのため、箱の長さの中に半波長がちょうど n 個入る波だけが許されます。波長が決まると、運動量が決まり、エネルギーは En = n²π²ħ²/(2mL²) となります。エネルギーが「とびとび」になるのは、波が閉じ込められているためです。

n = 1 の最低のエネルギーも、ゼロではありません。波が箱の中にある限り、波長が箱より長くはならないためで、これを零点エネルギーといいます。粒子を狭く閉じ込めるほど、E1 は大きくなります。

1つの固有状態の確率密度 |ψ|² は、時間がたっても変わりません。複数を重ね合わせると、エネルギー差 (En−Em)/ħ の角振動数で、確率密度が揺れ動きます。エネルギーを測ると、En が得られる確率は、重ねた量の2乗に比例します。

試してみよう

  1. 「n = 1」「n = 2」を選びます。節(波が 0 になる点)の数が、n − 1 になります。
  2. 「1 + 2」で、確率が左右に往復します。その周期は 2π/(E2−E1) です。
  3. 「1〜4」の量を調整して、波束のような山を作ります。n を多く足すほど、山が細くなります。

よくある疑問

n = 0 はないのですか。
n = 0 では波動関数が至るところで 0 になり、粒子がいないことになってしまいます。そのため、n = 1 から始まります。
固有状態のエネルギーは 1 つなのに、重ね合わせでは揺れるのはなぜですか。
重ね合わせの状態は、1つのエネルギーに定まっていないからです。2つの固有状態の位相が時間とともにずれるので、確率の山が動きます。

エネルギーが足りなくても、波は壁の向こうへしみ出す

波束を障壁にぶつけて、シュレーディンガー方程式を時間発展させます。障壁の高さや幅を変えて、通り抜ける割合の変化を見てください。

再生速度
波束のエネルギー E0
E と V₀ の関係—
透過率(理論)0
透過(いま)0
反射(いま)0

見どころ

  • E が V₀ より小さい(古典なら通れない)条件でも、波の一部は障壁の向こうに出ます。障壁の中では、確率密度が指数関数的に減っていきます。
  • 障壁を厚くすると、透過率は急激に小さくなります。幅のスライダーをゆっくり動かして、理論値の変化を見てください。
  • E が V₀ より大きい場合でも、一部は反射されます。古典力学では反射はゼロですが、波では境界で必ず反射が起きます。
  • V₀ を 0 にすると、波束はそのまま通り抜けながら、少しずつ広がっていきます。

式

E < V0: T = [ 1 + V0² sinh²(κa) / (4E(V0 − E)) ]−1,　κ = √(2m(V0 − E)) / ħ E > V0: sinh を sin に、κ を k′ = √(2m(E − V0)) / ħ に置き換える

ħ = m = 1 の単位です。理論値は、波束に含まれる波数のばらつきで平均した値です。画面の両端では波を吸収しています。

もう少し詳しく

古典力学では、粒子のエネルギーが壁の高さより低いと、壁を越えられません。量子力学では、波動関数は壁の中へ指数関数的に減衰しながら入り込み(κ = √(2m(V0−E))/ħ)、壁が有限の幅なら、向こう側に波が出ていきます。これがトンネル効果です。

通り抜ける確率は、壁が十分に厚いとき、およそ e−2κa に比例します。壁を高く、または厚くすると、指数関数的に減ります。粒子が軽いほど κ が小さく、通り抜けやすくなります。

エネルギーが壁より高くても、波の一部は反射します。壁の中の波長と壁の幅が、特定の関係(壁の中に半波長の整数個)になると、反射が消えて、完全に通り抜ける共鳴が起きます。トンネル効果は、走査型トンネル顕微鏡や、原子核のアルファ崩壊、トンネルダイオードなどに使われています。

試してみよう

  1. 障壁の幅 a を倍にして、通り抜ける割合の変化を見ます。幅に対して、指数関数的に減っていきます。
  2. 波束の波数 k を大きくして、E を V0 より大きくします。それでも一部が反射します。
  3. 「波の実部も表示」を入れて、壁の中で波が振動せず、減衰する様子を見ます。

よくある疑問

粒子は壁の中を、いつ通りますか。
壁の中を、ふつうの意味で「通り抜けている粒子」を見ることはできません。波動関数が壁の向こうまで続いていて、向こう側で粒子が見つかる確率がある、ということです。
T と R の和が 1 になるのはなぜですか。
粒子が、通り抜けるか反射するかのどちらかで、全体の確率が 1 だからです。数値計算では、端で吸収された分も考慮して 1 を確かめています。

位置を絞るほど、運動量はばらつく

自由に進む粒子のガウス波束です。位置の幅を変えて、運動量の幅と、時間とともに広がる速さを見比べてください。

再生速度
位置の幅 Δx0
運動量の幅 Δp0
Δx · Δp(下限 0.5)0
広がる時間の目安 2σ²0

見どころ

  • 位置の幅 σ を小さくすると、運動量の分布(下の図)が太くなります。波を細い山に押し込むには、さまざまな波長の波を足さなければならないからです。
  • Δx · Δp は、最初は 0.5(= ħ/2)で、ガウス波束が取りうる最小の値です。時間が進むと、位置が広がるので積は大きくなります。
  • 運動量の分布は時間が経っても変わりません。自由粒子では運動量が保存するためです。位置だけが広がるのは、速い成分と遅い成分が少しずつずれていくからです。
  • σ が小さい波束ほど、広がるのが速くなります。広がる時間の目安は 2mσ²/ħ です。

式

Δx · Δp ≥ ħ/2 Δx(t) = σ √(1 + (ħt / 2mσ²)²),　Δp = ħ / 2σ

ħ = m = 1 の単位です。波束の形は、解析的に求めた厳密な式で描いています。

もう少し詳しく

波を細い山に押し込もうとすると、さまざまな波長の波を足し合わせなければなりません。位置の幅 Δx を小さくすると、運動量の幅 Δp が大きくなるのは、そのためです。この関係が Δx·Δp ≥ ħ/2 で、等号が成り立つのがガウス型の波束です。

これは測定の技術的な限界ではなく、波としての粒子の性質です。運動量は波長で決まり、1つの波長の波は空間全体に広がるので、位置と運動量を同時に細く決めることはできません。

運動量にばらつきがあると、速い成分は先へ、遅い成分は後ろに残るので、波束はだんだん広がります。広がる時間の目安は 2mσ²/ħ で、最初に細く絞った波束ほど、速く広がります。

試してみよう

  1. σ を小さくします。運動量分布が太くなり、波束がすぐに広がります。
  2. σ を大きくします。運動量が揃い、広がりがゆっくりになります。
  3. 運動量分布の太さが、ほぼ 1/σ に比例して変わるのを確かめます。

よくある疑問

測定が粒子を乱すからではないのですか。
それは別の話です。不確定性関係は、測定をする前から、状態そのものが持つ性質です。
σ を小さくし続けるとどうなりますか。
運動量が大きくばらつき、エネルギーも大きくなります。位置を完全に決めた極限では、運動量がまったく決まらなくなります。

等間隔のはしごと、古典の振動子にそっくりな波束

放物線のポテンシャルの中の量子では、エネルギー準位が等間隔に並びます。準位を重ね合わせると、波束が行ったり来たりします。

状態の種類
平均エネルギー ⟨E⟩0
平均位置 ⟨x⟩0
広がりの積 Δx·Δp0

見どころ

  • 固有状態は、どの n でも時間がたっても形が変わりません。n が大きいほど、節(密度がゼロの点)が増え、古典的な往復運動の端の近くに山ができます。
  • 準位の間隔はどこも ħω で等しく、いちばん下の n = 0 でも E = ½ ħω のエネルギーが残ります(零点エネルギー)。
  • 隣り合う2つの準位を重ね合わせると、密度の山が周期 2π/ω で左右に揺れます。揺れの周期は、エネルギー差から決まります。
  • コヒーレント状態は、n = 0 と同じ形のガウス波束が、形を保ったまま古典の振動子と同じ運動をする状態です。Δx·Δp は最小値の ½ で、広がりません。
  • 自由粒子の波束は広がっていきましたが、放物線の井戸の中では、復元力のおかげで広がりません。

式

En = (n + ½) ħω |α⟩ = e−|α|²/2 Σ (αn/√n!) |n⟩

ħ = m = ω = 1 の単位です。波動関数は、エルミート多項式の漸化式で作った固有関数を足し合わせて、毎フレーム計算しています。

もう少し詳しく

放物線のポテンシャル V = ½ m ω² x² の中の粒子は、エネルギーが E = (n + ½) ħω という等間隔の値だけをとります。隣り合う準位の間隔がどこでも ħω で等しいのが、この系の特徴です。いちばん下の n = 0 でも ½ ħω が残るのは、位置を井戸の底に絞るほど運動量がばらつく、という不確定性関係の結果です(零点エネルギー)。

固有状態の確率密度は、時間がたっても変わりません。しかし、エネルギーの異なる固有状態を重ね合わせると、各成分が e^{−iEt/ħ} で位相をずらしながら回るので、密度が動き出します。隣り合う2つの準位なら、動きの周期は 2π/ω です。

コヒーレント状態は、固有状態をポアソン分布の重みで重ね合わせた状態です。波束の形が変わらず、中心が古典の振動子と同じ x = x₀ cos ωt で動きます。レーザー光の量子的な状態としても、よく使われます。

試してみよう

  1. 「固有状態」で n を 0 から 7 まで動かして、節の数が n 個であることを確かめます。
  2. 「2準位の重ね合わせ」で n = 0 にして、山が左右に揺れる様子を見ます。n を増やしても、揺れの周期が変わらないことを確かめます。
  3. 「コヒーレント状態」で α を大きくして、振幅は変わっても形が変わらないことを確かめます。

よくある疑問

n = 0 でもエネルギーがゼロでないのはなぜですか。
粒子を井戸の底の一点に止めると、位置の幅がゼロになり、不確定性関係から運動量が無限にばらつくからです。位置と運動量の広がりのバランスで、最小のエネルギー ½ ħω が決まります。
波束が広がらないのは、自由粒子と何が違うのですか。
自由粒子は、運動量の成分ごとに速さが違うので広がります。調和振動子では、すべての成分が同じ周期で往復するので、周期ごとに元の形に戻ります。

電子の雲は、量子数ごとにまったく違う形をしている

水素原子の電子が見つかりやすい場所を、原子核を通る断面で見ます。量子数 n、l、m を変えて、s、p、d の軌道の形を確かめてください。

軌道—
エネルギー—
平均の距離 ⟨r⟩—
節の数(球面 / 平面)—

見どころ

  • 1s は、中心がいちばん濃い球対称の雲です。ただし、電子が「核からちょうど r のところ」に見つかる確率は、体積が r² で増えるぶん、r = 1(ボーア半径)でいちばん大きくなります。下のグラフの山がそれです。
  • l = 1(p 軌道)は、中心で密度がゼロの、2つの葉をもつ形です。m を 0 から 1 に変えると、葉の向きが z 軸の方向から x 軸の方向へ変わります。
  • n を大きくすると、雲は n² に比例して広がり、動径方向に n − l − 1 個の節(球面状の密度ゼロの殻)ができます。2s の中のくぼみがその一例です。
  • 水素原子のエネルギーは n だけで決まります。同じ n で l や m が違う軌道は、同じエネルギーをもちます(縮退)。

式

En = −13.6 eV / n² ψnlm(r, θ, φ) = Rnl(r) Ylm(θ, φ)

実数で表した軌道(m ≠ 0 は cos mφ 型)の、x–z 断面です。原子単位で、距離の単位はボーア半径(約 0.053 nm)です。

もう少し詳しく

水素原子の電子の状態は、3つの量子数 n、l、m で決まります。エネルギーは n だけで決まり、E = −13.6 eV / n² です。l(0, 1, 2, … = s, p, d, …)は軌道の形、m はその向きを表します。l は n − 1 以下、|m| は l 以下の整数に限られます。

波動関数は、動径方向の関数 R(r) と、角度方向の関数(球面調和関数)の積です。図に描いたのは、電子の見つかる確率密度 |ψ|² の断面です。s 軌道(l = 0)は球対称で、p 軌道(l = 1)は2つの葉、d 軌道(l = 2)は4つの葉(またはリングつきの2つの葉)をもちます。

節(密度がゼロの面)の総数は n − 1 個で、そのうち l 個は角度方向の平面(または円錐面)、残りの n − l − 1 個は動径方向の球面です。化学で習う軌道の形や、原子の周期表の並び方の背景に、この量子数の制限があります。

試してみよう

  1. n = 1、l = 0 から始めて、n を増やします。動径方向の節が増えていく様子を、下のグラフで確かめます。
  2. n = 2 で l = 1 にして、m を 0 と 1 で切り替えます。葉の向きが変わります。
  3. n = 3 で l を 0、1、2 と増やして、節の位置と数がどう変わるか見比べます。

よくある疑問

電子は、核のまわりを回っているのではないのですか。
図の濃淡は、電子を見つけたときの位置の確率分布です。軌道運動のような軌跡ではありません。電子の状態は、定常的な雲のように広がっています。
m ≠ 0 の図が、教科書で見る複素数の球面調和関数と違って見えるのはなぜですか。
ここでは、m と −m を足し引きして作った実数の軌道(cos mφ 型)を描いています。化学の教科書の px、dxz などの形に対応します。

スピンは磁場のまわりを回り、測ると上か下かに決まる

スピン 1/2 の状態は、球の上の矢印(ブロッホベクトル)で表せます。磁場をかけると、矢印は磁場の向きのまわりを一定の速さで回ります。

はじめの向き
測ると上向きになる確率0
回る周期 2π/ω0
直近の測定結果—

見どころ

  • はじめが +z で、磁場も z 軸に平行なら、スピンは動きません。磁場を z 軸から傾けると、スピンは磁場のまわりに円錐を描いて回り(歳差運動)、上向きの確率が周期的に変わります。
  • 磁場を z 軸に垂直(90°)にすると、上向きの確率が 1 から 0 まで往復します。これがラビ振動で、核磁気共鳴(NMR、MRI の原理)の基礎です。
  • 磁場と同じ向き(または逆向き)のスピンは、回転軸の上にあるので動きません。「+x」から始めて磁場を 0° にすると、回転のようすがいちばんよくわかります。
  • 「z 軸で測定する」を押すと、確率 (1 + ⟨σz⟩)/2 で上か下かに決まり、矢印は +z か −z に飛びます。測定の前の向きの情報は、確率の形でしか残りません。

式

H = (ħω/2) B̂ · σ,　d⟨σ⟩/dt = ω B̂ × ⟨σ⟩ P↑(t) = 1 − sin²β sin²(ωt/2)(はじめが +z のとき)

磁場は x–z 面の中で傾けています。状態は2成分の複素数の組で、時間発展を厳密に計算しています。

もう少し詳しく

電子のスピンは、測ると「上」か「下」の2通りの値だけが得られる量です。測る前の状態は、2つの複素数(上と下の重ね合わせの係数)で決まり、球面上の1点(ブロッホ球)に対応させて矢印で表せます。

スピンを磁場の中に置くと、エネルギーが磁場との向きで変わります。その結果、矢印は磁場の向きのまわりを一定の角速度で回ります(ラーモア歳差運動)。回る速さは磁場の強さに比例します。上向きの確率が時間とともに変わる様子は、ラビ振動と呼ばれます。

測定すると、確率 (1 + ⟨σz⟩)/2 で上向き、残りの確率で下向きが得られ、状態はその向きに飛びます。1回の測定結果はランダムですが、同じ状態をたくさん用意して測ると、確率の予言どおりの割合になります。MRI は、この歳差運動の周波数を使っています。

試してみよう

  1. はじめの向きを +z、磁場を 90° にして、上向きの確率が 1 から 0 へ往復するのを見ます。
  2. 磁場を 0°(z 軸に平行)にして、+x から始めます。矢印が赤道を回ります。
  3. 「z軸で測定する」を何度か押して、結果がばらつくことと、その割合が表示された確率に近づくことを確かめます。

スピンが「回っている」のは、電子が自転しているのですか。
古典的な自転とは違います。スピンは、電子がもともともっている内部の量で、磁場の中での振る舞いが、回転する小さな磁石に似ているだけです。
測定した後、矢印が +z か −z に飛ぶのはなぜですか。
測定で上向きという結果が得られたら、その後で続けて測っても、同じ結果が得られる必要があります。そのため、状態は測定した結果に対応する状態に変わります(波束の収縮)。
