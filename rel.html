特殊相対論ラボ

「光の速さは、誰から見ても同じ」という1つの原理から、時間の遅れ、同時刻の食い違い、速さの上限が導かれます。光時計、ミンコフスキー図、一定の力での加速の3つで確かめます。

動いている時計は、ゆっくり進む

2枚の鏡の間を光が往復するだけの「光時計」を使います。光の速さは、どの人から見ても同じです。そのため、動く時計の中の光は、地上から見ると長い道のりを進み、1往復に長くかかります。

見どころ

  • 左の絵では、動く時計の光が、地上の時計より、ゆっくり往復します。右の絵は、その理由です。地上から見ると、動く時計の光は斜めに進み、道のりが長くなります。光の速さは変わらないので、往復にかかる時間が長くなります。
  • 鏡の間隔を h とすると、地上から見た片道の時間は t = γh/c です(下の式を解いたものです)。つまり、動く時計の1目盛りは、地上の時計の γ 目盛り分に相当します。
  • 速さが小さいうちは、γ はほぼ 1 で、違いは感じられません。β = 0.99 では、γ ≈ 7.1 になります。
  • 寿命が約 2.2 マイクロ秒のミューオンが、上空で生まれて地上まで届くのは、この効果のためです。地上から見ると、ミューオンの寿命は γ 倍に延びています。
(ct)² = h² + (vt)²　⟹　t = h / (c√(1−β²)) = γt0,　γ = 1/√(1−β²)

動く時計の「地上から見た進み」を、数値で求めた光の到着時刻と照らして確かめています。ミューオンの寿命は 2.197 マイクロ秒としました。

もう少し詳しく

特殊相対論の出発点は、「光の速さは、誰から見ても同じ」という原理です。光時計では、この原理だけから時間の遅れが導かれます。動く時計の光は、地上から見ると斜めに進んで、道のりが長くなります。光の速さは変わらないので、1往復の時間が長くなります。ピタゴラスの定理で、t = γh/c が得られます。

時間が遅れるのは、光時計に限りません。生物の時計や、原子の振動を含め、どんな時計も同じ割合で遅れます。もし時計の種類で違えば、動いていることを、時計の中だけで検出できてしまうからです。

この効果は、現実に測られています。ミューオンは、静止していると平均2.2マイクロ秒で壊れ、光の速さで走っても約660メートルしか進めません。しかし、上空で生まれたミューオンの多くは地上まで届きます。γ が大きく、地上から見た寿命が延びているからです。GPS 衛星の時計も、速さのために1日あたり約7マイクロ秒遅れます(重力による進みも加わって、実際には全体で約38マイクロ秒進みます)。

試してみよう

  1. β を 0.6 にします。γ はちょうど 1.25 です。地上の時計が5目盛り進むと、動く時計は4目盛りになります。
  2. β を 0.99 にします。γ ≈ 7.1 で、ミューオンの見かけの寿命が、約15.6マイクロ秒になります。
  3. 右の絵で、光の道のりが長くなる様子を見ます。速くなるほど、斜めの線が緩やかになります。

よくある疑問

動く時計の側から見ると、どうなりますか。
動く時計の上の人は、自分は止まっていると考えます。その人から見ると、遅れているのは地上の時計のほうです。時間の遅れは、お互いさまです。
光時計でしか成り立たないのですか。
どんな時計でも成り立ちます。相対性原理により、慣性系はどれも同等なので、時計の仕組みによる違いは出ません。

動く人の座標軸は、時空図の上で傾く

横軸に位置 x、縦軸に時間 ct をとった図です。速さ β で動く人にとっての座標軸(紫)は、光の線(45°)に向かって、両側から傾きます。点 P を動かして、座標の値の変わり方を見てください。

ローレンツ因子 γ
P(地上)( x, ct )
P(動く人)( x′, ct′ )
間隔 (ct)² − x²
地上で測った棒の長さ

見どころ

  • P を図のどこに置いても、光の線(45°)は、動く人の軸にとっても 45° のままです。これが光速不変の表れです。
  • 動く人の x′ 軸と平行な直線は、動く人にとっての「同じ時刻」です。傾いているので、地上で同時の2つの出来事は、動く人にとっては同時ではありません(同時刻の相対性)。
  • 間隔 (ct)² − x² は、β を変えても動きません。時間的(正)なら、順序が全員にとって同じで、原因と結果になり得ます。空間的(負)なら、順序が人によって入れ替わりますが、そのため、互いに影響は与えられません。
  • 棒の両端の世界線(橙)が、地上の「同じ時刻」(ct = 0 の線)と交わる間隔が、地上で測った長さです。1/γ に縮んでいます。
x′ = γ(x − β ct),　ct′ = γ(ct − βx) x′ 軸: ct = βx　/　ct′ 軸: x = β ct

もう少し詳しく

時空図では、1つの出来事が1つの点になり、物体の動きは「世界線」という線になります。光の世界線は、どの人にとっても 45° の線です。この線で区切られた円錐(光円錐)の内側は、原因と結果が結べる範囲で、外側は、どんな信号も届かない範囲です。

速さ β で動く人の座標軸は、光の線を挟んで、対称に傾きます。その人にとっての「同じ時刻」は、傾いた x′ 軸に平行な線です。地上で同時の2つの出来事が、動く人にとっては同時でなくなるのは、このためです。長さの収縮も、同じ図から読み取れます。

どの座標でも変わらないのは、間隔 (ct)² − x² です。正なら時間的で、出来事の順序は全員にとって同じです。負なら空間的で、順序は人によって入れ替わります。ただし、互いに影響を及ぼせない関係なので、因果の矛盾は起きません。

試してみよう

  1. β を 0 から 0.95 まで動かします。2本の紫の軸が、光の線に近づいていきます。
  2. P を「空間的」にして、β を大きくします。ct′ の値が、負に変わる瞬間があります。順序が入れ替わった、ということです。
  3. P を「光の線の上」にします。β をどう変えても、間隔は 0 のままで、x′ = ct′ になります。

よくある疑問

光より速く動けるのですか。
空間的な間隔の2点は、光より速い動きでないと結べません。そのような動きや信号は、特殊相対論では許されません。
なぜ軸は両側から傾くのですか。
光の線が、どの座標でも 45° のままでなければならないからです。そのため、x′ 軸と ct′ 軸は、光の線について対称になります。

力を加え続けても、光の速さには届かない

一定の力で粒子を押し続けます。ニュートン力学では、速さは時間に比例して、いつか光の速さを超えます。相対論では、運動量は増え続けても、速さは光の速さに近づくだけです。

相対論の速さ v/c
ニュートン力学の速さ
ローレンツ因子 γ
運動量 p (mc)
運動エネルギー (γ−1)mc²
ニュートン力学の ½mv²

見どころ

  • 低い速さのうちは、2本の線は重なっています。ニュートン力学は、遅い世界でよく合う近似です。
  • ニュートン力学の速さ(橙)は、t = 1 で光の速さに達し、その先で超えてしまいます。相対論(青)は、いくら押しても光の速さの手前に留まります。
  • 押し続けた力は、運動量とエネルギーを増やし続けます。速さが増えない代わりに、エネルギーは γ に比例して増えます。力のする仕事 Fx は、運動エネルギー (γ−1)mc² に等しくなります。
  • 下の絵では、ニュートン力学の粒子(橙)は、やがて光(紫)を追い越します。相対論の粒子(青)は、光に追いつけません。
p = Ft,　v/c = p / √(m²c² + p²),　E² = (pc)² + (mc²)² x = (mc²/F)(√(1 + (Ft/mc)²) − 1)

m = c = 1 の単位です。解析式は、運動方程式を数値で積分した結果と照らして確かめています。

もう少し詳しく

力 F が運動量の変化率 dp/dt を決めるのは、相対論でも変わりません。違うのは、運動量が p = γmv になることです。速さが光の速さに近づくと、γ が急に大きくなるので、わずかな速さの増加にも大きな運動量が必要になります。そのため、力を加え続けても、速さは光の速さの手前で頭打ちになります。

全エネルギーは E = γmc²、静止エネルギーは mc² です。運動エネルギーは (γ−1)mc² で、速さが小さいときは ½mv² に一致します。力のする仕事 Fx は、この運動エネルギーに等しくなります。

加速器は、この性質を使っています。電子(静止エネルギー約0.511メガ電子ボルト)を、1メガボルトで加速すると、γ ≈ 3 になり、速さは光の約94%です。ここで速さの増加はわずかでも、エネルギーは何倍にも増えます。

試してみよう

  1. 時間を 0.1 付近に動かします。相対論とニュートン力学の速さは、ほぼ同じです。
  2. 時間を 1 まで動かします。ニュートン力学の速さは 1(光速)に達しますが、相対論では約 0.71 です。
  3. 時間を 5 まで動かします。γ とエネルギーの増え方を見ます。速さは、ほとんど増えません。

よくある疑問

質量が増えるのですか。
現在は、質量は粒子に固有で不変とする考え方が標準です。速さが上がるにつれて増えるのは、運動量とエネルギーです。
光の速さで動く粒子はありますか。
質量のない粒子(光子など)だけが、光の速さで動けます。質量のある粒子は、光の速さに近づけますが、届きません。
